Entry for the [Pigeon Pitch, One Line](https://make.fun/bounty/u-donrulezz-pigeon-pitch-one-line-af06c6cf) bounty on make.fun.

## What it does

`main.py` (Python standard library only, fully deterministic) writes a
single-line elevator pitch — a city pigeon pitching its startup to
investors — to `/output/entry.txt`. The pitch is one line, in English,
and at most 200 characters, as the bounty requires.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
